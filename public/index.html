About Me

Perkenalkan, saya Naufal Rakha Putra, hanya seorang web developer. Saya fokus pada pembangunan antarmuka web yang sederhana, cepat, dan estetis.

Saya berpengalaman menggunakan HTML, CSS, JavaScript, PHP dalam membangun beragam proyek personal, dari CMS video hingga framework CSS pribadi.

Saya percaya bahwa desain yang baik dimulai dari struktur kode yang bersih dan niat yang jelas.

Perjalanan saya sebagai developer bermula dari rasa penasaran kecil: bagaimana sebuah website bisa hidup hanya dari barisan kode? Dari situlah muncul dorongan untuk terus belajar, bereksperimen, dan menantang diri lewat proyek-proyek mandiri.

Filosofi saya sederhana: kode bukan hanya soal fungsi, tapi juga cerita. Setiap baris yang saya tulis berusaha menjawab satu pertanyaan: "Bagaimana caranya membuat orang lain merasa terbantu dan nyaman ketika menggunakannya?"

Yang membedakan saya dengan developer lain mungkin bukan sekadar teknologinya, tapi pendekatan saya yang selalu mencoba menggabungkan rasa ingin tahu, konsistensi, dan sedikit keberanian untuk berbeda. Saya percaya bahwa dunia web bukan hanya tempat menaruh konten, tapi medium untuk menyampaikan pengalaman.
