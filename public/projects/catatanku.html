Case Study

Catatanku

Aplikasi catatan digital untuk pelajar & mahasiswa

PHP Native · MySQL · Bootstrap 5 · DomPDF

S Situation

Pelajar dan mahasiswa sering kesulitan mengelola catatan kuliah karena terpencar di berbagai platform — buku tulis, Google Docs, WhatsApp, dan notes HP. Nggak ada sistem terpusat yang bisa dipakai buat nyimpen, ngatur, dan nyari catatan dengan cepat. Proyek ini juga tugas pertama full-stack dari nol tanpa framework, jadi harus ngerti fundamental backend-frontend sekaligus.

T Task

Bangun aplikasi catatan digital berbasis web dengan fitur CRUD, autentikasi pengguna, role-based access (user & admin), dan ekspor PDF. Develop dari nol tanpa framework buat nguatin pemahaman arsitektur web tradisional. Deploy ke shared hosting biar bisa dipake beneran.

A Action

Tech stack:

PHP Native MySQL Bootstrap 5 DomPDF JavaScript
  • Desain database relasional: users → notes → subjects dengan foreign key constraints
  • Implementasi session-based auth (register, login, forgot/reset password)
  • CRUD notes dengan prepared statements (PDO) anti SQL injection
  • Panel admin terpisah buat manajemen user, mata kuliah, dan semua catatan
  • Fitur ekspor PDF pake DomPDF — satu klik dari dashboard user
  • Bootstrap 5 + custom CSS buat responsive design di mobile & desktop
  • Deploy ke InfinityFree shared hosting (PHP + MySQL gratis)

R Result

  • Aplikasi fungsional dengan 5 fitur utama: auth, CRUD, admin panel, manajemen matkul, ekspor PDF
  • Bisa diakses dari desktop & mobile via responsive Bootstrap layout
  • Jadi batu loncatan belajar full-stack: session management, PDO, relasi database, RBAC, dan deployment
  • Source code tersedia di GitHub via github.com/sternnaufal/catatanku
