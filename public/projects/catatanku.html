Case Study

Catatanku

Aplikasi catatan digital untuk pelajar & mahasiswa

PHP Native · MySQL · Bootstrap

Deskripsi

Catatanku adalah aplikasi catatan digital berbasis web yang dirancang khusus untuk pelajar dan mahasiswa. Proyek ini adalah proyek PHP pertama yang dibangun dari nol tanpa framework, mengajarkan fondasi full-stack development mulai dari CRUD dasar hingga autentikasi, role-based access, dan ekspor PDF.

Dibangun saat masa SMK, Catatanku menjadi batu loncatan untuk memahami arsitektur web tradisional secara menyeluruh.

Teknologi

PHP Native MySQL Bootstrap 5 DomPDF JavaScript
  • Backend: PHP Native (tanpa framework)
  • Database: MySQL dengan relasi user-catatan-matkul
  • Frontend: Bootstrap 5 + custom CSS
  • PDF: DomPDF untuk ekspor catatan

Fitur

  • Registrasi & login pengguna
  • CRUD catatan (tambah, lihat, edit, hapus)
  • Manajemen mata kuliah (admin)
  • Role-based access: user biasa + admin panel
  • Ekspor catatan ke PDF
  • Forgot password & reset password
  • Responsive design (Bootstrap)

Struktur Proyek

catatanku/
  admin/        # Panel admin (user, matkul, catatan)
  user/         # Dashboard user (add, edit, delete note)
  public/       # Login, register, forgot/reset password
  includes/     # Auth, config, header, footer
  config/       # Koneksi database
  vendor/       # DomPDF & dependencies

Yang Dipelajari

  • PHP session management & autentikasi
  • CRUD dengan prepared statements (PDO)
  • Relasi database MySQL (user → catatan → matkul)
  • Role-based access control (user vs admin)
  • File upload & PDF generation
  • Deployment ke shared hosting (InfinityFree)

Status

Aplikasi masih hidup di InfinityFree (free hosting) namun domain pointing sudah dimatikan. Source code tersedia di GitHub.
