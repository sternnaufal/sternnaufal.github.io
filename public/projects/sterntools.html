Case Study

Sterntools

Toolkit CTF forensika digital

Shell · Linux · Cyber Security

S Situation

Dalam kompetisi CTF (Capture The Flag) kategori Forensics, banyak challenge yang butuh analisis file manual: cari metadata tersembunyi, ekstrak artefak dari binary, reverse image, scan jaringan, decode string. Kerja ini repetitive & nggak efisien kalau masih manual satu-satu. Butuh toolkit otomatisasi yang bisa dipake cepat saat kompetisi berjalan.

T Task

Bangun personal forensics toolkit berisi skrip-skrip Shell yang otomatisasi: file inspection, string extraction, metadata analysis, steganography check, network artifact scan, dan system investigation. Deploy ke GitHub buat portofolio cyber security.

A Action

Tech stack:

Shell (Bash) Linux CLI CTF
  • File Inspector: file, strings, binwalk, xxd wrapper — deteksi tipe file, extract hidden strings, cari embedded file
  • Metadata Extractor: exiftool wrapper — baca EXIF, GPS, kamera, timestamp dari gambar/doc
  • Image Analyzer: zsteg, steghide — cek steganography, LSB hiding, hidden data di gambar
  • Network Scanner: tshark wrapper — parse PCAP, extract HTTP traffic, DNS queries, suspicious packets
  • System Investigator: volatility wrapper — memory forensics: process list, network connections, file system scan
  • Setiap tool dibungkus dalam fungsi bash reusable dengan output color-coded & flags

R Result

  • Toolkit dengan 5+ tool utama siap pake untuk CTF forensics
  • Mengurangi waktu analisis manual dari 30 menit → 2 menit per challenge
  • Dipake pribadi di Zero Day National CTF 2026 & picoCTF 2026
  • Open-source: GitHub
  • Validasi skill: Linux CLI + File forensics + Network analysis + Memory forensics
