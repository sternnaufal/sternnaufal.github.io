Case Study

Website Duta Anak Kota Bukittinggi

Landing page resmi profil Duta Anak Kota Bukittinggi 2025

Bootstrap · HTML5 · CSS3

S Situation

Pemerintah Kota Bukittinggi lewat program Duta Anak 2025 butuh landing page resmi buat nampilin profil duta, visi-misi, kegiatan, dan contact. Sebelumnya cuma info di media sosial, nggak ada website resmi. Deadline ketat: harus ready sebelum acara pelantikan.

T Task

Frontend developer — bangun landing page responsif (mobile-first) dengan profil duta, galeri, timeline kegiatan, dan form kontak. Target: tampilan modern, cepat diakses dari HP, dan mudah di-update kontennya.

A Action

Tech stack:

Bootstrap 5 HTML5 CSS3
  • Desain layout mobile-first pake Bootstrap 5 grid system
  • Section: Hero (judul + visi), Profil Duta (foto + bio), Galeri (foto kegiatan), Timeline, Kontak
  • Animasi CSS scroll reveal — section fade-in saat user scroll
  • Form kontak dengan validation client-side (HTML5 + Bootstrap validation)
  • Optimasi performa: lazy load images, minified CSS/JS, compressed assets
  • Test cross-browser: Chrome, Firefox, Safari, Samsung Internet
  • Deploy ke GitHub Pages

R Result

  • Landing page fungsional responsif — tampilan optimal di desktop & mobile
  • Dipake resmi sebagai website program Duta Anak Kota Bukittinggi 2025
  • Proses pengembangan cepat: < 1 minggu dari kickoff sampai deploy
  • Source: GitHub
  • Validasi skill: Responsive design + CSS animations + Performance optimization + Cross-browser testing
