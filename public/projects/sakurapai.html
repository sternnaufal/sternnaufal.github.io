Case Study

Sakurapai (CMS Video)

Content Management System video streaming

PHP Native · MySQL · JavaScript

S Situation

Butuh sistem video streaming pribadi dengan kontrol akses penuh — upload, kelola, dan putar video tanpa ketergantungan pihak ketiga (YouTube, Vimeo). Kebutuhan ini muncul dari keinginan punya platform video sendiri yang aman dan bisa diatur aksesnya per-user.

T Task

Bangun CMS video berbasis web dengan fitur registrasi & login, upload & streaming video, manajemen konten via admin panel, dan kontrol akses pengguna. Sistem harus bisa handle upload file video besar dan streaming lancar.

A Action

Tech stack:

PHP Native MySQL JavaScript HTML5 Video
  • Desain database: tabel users, videos, categories dengan relasi user→video
  • Sistem session-based auth untuk login/register pengguna
  • Fitur upload video dengan validasi tipe file & ukuran
  • Integrasi HTML5 video player untuk streaming di browser
  • Admin panel untuk manajemen: tambah/edit/hapus video, kelola user, atur kategori
  • Sistem role-based access: admin punya akses penuh, user biasa hanya bisa lihat konten yang diizinkan
  • Deploy ke shared hosting dengan PHP + MySQL

R Result

  • CMS video fungsional dengan 3 modul utama: auth, manajemen video, admin panel
  • Bisa upload & streaming video langsung dari browser tanpa platform pihak ketiga
  • Source code tersedia di GitHub
