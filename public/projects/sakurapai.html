Case Study

Sakurapai

CMS Video Anime dengan sistem premium & monetisasi

Deskripsi

Sakurapai adalah Content Management System (CMS) video yang berfokus pada konten anime. Proyek ini dikembangkan untuk mempermudah pengelolaan video, interaksi pengguna, serta monetisasi melalui sistem langganan dan iklan.

Fitur Utama

  • Autentikasi pengguna (registrasi & login)
  • Upload & tonton video dengan thumbnail
  • Interaksi: like, dislike, komentar
  • Pengelompokan video berdasarkan kategori anime
  • Sistem role-based:
    • Member: nonton gratis dengan iklan
    • VIP/Premium: tanpa iklan, akses konten premium, unduh video
  • Statistik video populer (berdasarkan like & views)
  • Monetisasi: Trakteer (Rp5.000/bulan), iklan (Infolinks, Adsterra, dll), donasi

Teknologi

  • Frontend: HTML, CSS, JavaScript + Bootstrap
  • Backend: PHP Native
  • Database: MySQL

Struktur Proyek

sakurapai/
  admin/          # Panel admin
  assets/         # CSS, JS, images
  includes/       # Konfigurasi & helper
  uploads/        # Video & thumbnail
  index.php       # Halaman utama
  category.php    # Halaman kategori
  title.php       # Halaman judul anime
  403.php         # Akses ditolak
  404.php         # Tidak ditemukan

Cara Menjalankan

  1. Clone repositori: 
    git clone https://github.com/sternnaufal/sakurapai.git
  2. Import sakurapai.sql ke MySQL
  3. Atur koneksi database di includes/config.php
  4. Jalankan di XAMPP / Laragon / LAMP
