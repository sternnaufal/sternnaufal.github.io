Case Study

Keepsimple

Framework CSS ringan & fleksibel — fokus pada kesederhanaan

Pengenalan

Keepsimple adalah library CSS ringan dan serbaguna, dirancang untuk memberikan styling sederhana pada proyek web development. Dengan fokus pada simplicity dan flexibility, Keepsimple menyediakan kumpulan gaya yang mudah diintegrasikan ke struktur HTML kamu.

Instalasi

Download file CSS dan host secara lokal di proyekmu, atau gunakan CDN:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/sternnaufal/keepsimple/keepsimple.css">

Cara Menggunakan

Styling Dasar

Tambahkan class ke elemen HTML:

<div class="light">Ini elemen terang.</div>
<div class="dark">Ini elemen gelap.</div>

Navbar

<div class="navbar-con">
  <!-- Konten navbar -->
</div>

Fonts

TypeScripter: <p class="typescripter">Teks</p>
Gothic:       <p class="gothic">Teks</p>
Modern:       <p class="modern">Teks</p>
Lucida:       <p class="lucida">Teks</p>
Traditional:  <p class="traditional">Teks</p>

Layout

Container

<div class="container">
  <!-- Konten -->
</div>

Layout Responsif

<div class="big">Container besar</div>

<div class="flex">
  <div class="flexbox"></div>
</div>
