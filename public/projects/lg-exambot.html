Case Study

LG-Exambot

AI auto exam question generator — produk komersial

Laravel · Gemini API · DeepSeek · Groq

S Situation

Lembaga pendidikan butuh generator soal ujian otomatis untuk menghemat waktu guru. Tantangan: model AI kadang down, rate-limited, atau hasilnya nggak konsisten. Butuh sistem yang andalan (reliable) dengan fallback otomatis ke provider AI lain kalau yang utama gagal. Produk ini dikomersialkan dengan harga Rp2.500.000.

T Task

Developer utama membangun sistem generator soal berbasis AI dengan arsitektur multi-provider fallback. Full ownership: backend Laravel, integrasi 3 provider AI, sistem kredit user, panel admin, hingga deployment production.

A Action

Tech stack:

Laravel Gemini API DeepSeek Groq
  • Arsitektur AI cascade fallback: Custom API → Gemini → DeepSeek → Groq (otomatis ganti kalau error/rate-limit)
  • Bangun Laravel backend dengan modul: manajemen soal, user kredit, transaksi, export PDF/Word
  • Implementasi prompt engineering untuk generate soal pilihan ganda, essay, true/false, matching
  • Sistem credit-based billing — user beli kredit, tiap generate soal potong kredit
  • Admin panel: kelola user, lihat usage, atur harga kredit, monitoring API health
  • Export soal ke PDF & Word (dompdf + PhpWord)
  • Deploy production di VPS/Shared Hosting dengan domain custom exambot.l-glearning.com
  • Integrasi payment gateway buat pembelian kredit otomatis

R Result

  • Produk komersial terjual Rp2.500.000 per lisensi
  • Fallback AI 99.9% uptime — sistem auto-switch provider tanpa interupsi user
  • Live production di exambot.l-glearning.com
  • Source code: GitHub
  • Validasi skill: Laravel + AI integration + payment + SaaS architecture
