Case Study

Hanekawa Bot v4

Discord bot serbaguna — moderasi, musik, tiket, translasi

JavaScript · Discord.js

S Situation

Komunitas Discord butuh bot all-in-one yang bisa handle moderasi (kick, ban, mute, warn), musik, sistem tiket support, translasi otomatis, dan utility lain. Kebanyakan bot gratis punya fitur terbatas & limit rate, sementara bot premium mahal. Butuh bot custom yang fully kontrollable untuk server sendiri.

T Task

Sebagai sole developer, bangun Discord bot v4 pake Discord.js yang modular — bisa ditambahin command baru tanpa refactor. Full feature: moderasi, musik, tiket, translasi, info, fun. Deploy & maintain production.

A Action

Tech stack:

JavaScript (ES6+) Discord.js v14 FFmpeg
  • Arsitektur modular command handler — tiap command = file terpisah, auto-register via bot startup
  • Moderasi: /kick, /ban, /unban, /mute (timeout), /warn — dengan logging ke mod-log channel
  • Musik: play, pause, skip, queue, disconnect — pake FFmpeg + voice channel streaming
  • Sistem tiket: buka tiket otomatis → panel → admin bisa claim → resolve & close
  • Translasi: auto-detect bahasa, translate pesan dengan API translator
  • Slash commands (Discord v10+) — interaction-based, nggak legacy prefix
  • Deploy ke VPS dengan pm2 process manager, auto-restart

R Result

  • Bot v4 fully functional dengan 5+ modul utama
  • Modular architecture — tambah command tanpa ubah core
  • Slash command Discord API — compliant dengan Discord developer policy
  • Open-source: GitHub
  • Validasi skill: Discord API + Voice streaming + Event-driven architecture + Process management
