Case Study

Telegram Bot Reminder

Bot pengingat jadwal otomatis terintegrasi Google Calendar

Python · Google Calendar API

S Situation

Pribadi & teman sering lupa jadwal kuliah, meeting, deadline karena terpencar di Google Calendar, Notion, dan WhatsApp. Butuh bot Telegram sederhana yang bisa baca jadwal dari Google Calendar dan kirim reminder otomatis ke chat pribadi/grup.

T Task

Bangun Telegram bot Python yang terintegrasi Google Calendar API. Fitur: sinkron jadwal harian, kirim reminder jam H-1 & H-0, support multiple calendar, command interaktif buat lihat jadwal hari ini.

A Action

Tech stack:

Python 3.10+ Google Calendar API python-telegram-bot OAuth2
  • Setup Google Cloud Console project + enable Calendar API + OAuth2 credentials
  • Implementasi OAuth2 flow buat user autentikasi & grant akses calendar
  • Bangun Telegram bot pake python-telegram-bot library (async)
  • Fitur scheduled jobs (APScheduler) buat cek calendar setiap jam & kirim reminder
  • Command bot: /start, /today, /week, /calendars, /settings
  • Simpan refresh token terenkripsi buat akses calendar tanpa login ulang
  • Deploy ke VPS/Serverless dengan systemd/service manager

R Result

  • Bot fungsional dengan 5+ command interaktif
  • Reminder otomatis H-1 & H-0 ke Telegram pribadi/grup
  • Support multiple Google Calendar per user
  • Source code open-source: GitHub
  • Validasi skill: Python async + OAuth2 + Google API + Telegram Bot API + Scheduling
