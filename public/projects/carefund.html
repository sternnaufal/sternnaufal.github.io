Case Study

CareFund

Platform crowdfunding medis full-stack

React.js · Node.js · Express · MySQL

S Situation

Project-based learning (PBL) kampus menuntut mahasiswa membangun produk nyata untuk stakeholder beneran. Dosen memberi tantangan: buat platform crowdfunding medis yang memudahkan pasien butuh biaya pengobatan besar. Tim 3 mahasiswa, tenggat waktu ketat, harus kerjasama full-cycle development — dari desain database sampai deployment.

T Task

Sebagai Full-Stack Developer dalam tim 3 orang, tanggung jawabku: arsitektur database, REST API backend, integrasi frontend-backend, dan deployment. Kolaborasi langsung dengan dosen sebagai stakeholder utama buat requirement gathering & review.

A Action

Tech stack:

React.js Node.js Express MySQL
  • Rancang skema database relasional: users, campaigns, donations, categories, withdrawals
  • Bangun REST API Express.js: auth JWT, CRUD campaign, donasi, tracking status, statistik admin
  • Frontend React.js dengan state management & form validasi kompleks
  • Implementasi fitur utama: manajemen campaign (buat, edit, publish), sistem donasi, dashboard user/admin
  • Integrasi payment gateway simulasi buat flow donasi end-to-end
  • Deploy: Frontend ke Vercel, Backend ke Vercel Serverless, DB ke PlanetScale/MySQL
  • Dokumentasi API & kolaborasi via GitHub Organization

R Result

  • Platform crowdfunding fungsional penuh dengan 5+ modul utama
  • Deployed live di Vercel (frontend & API)
  • Diterima sebagai proyek PBL selesai dengan review positif dari dosen stakeholder
  • Portofolio kolaborasi tim & full-stack production-ready
