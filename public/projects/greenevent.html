Case Study

GreenEvent

Platform manajemen acara lingkungan hidup

Laravel · Blade · MySQL

S Situation

Kompetisi Creanomic Vokasi UB 2025 menantang tim buat solusi digital bidang lingkungan. Masalah: organisasi susah kelola event planting, cleanup, workshop — registrasi manual, tracking kehadiran pakai kertas, reporting susah. Butuh platform terintegrasi dari pendaftaran sampai laporan.

T Task

Full-Stack Developer membangun platform event management end-to-end untuk kompetisi. Tanggung jawab: arsitektur sistem, backend API, frontend Blade, database design, deployment. Deadline ketat kompetisi.

A Action

Tech stack:

Laravel Blade MySQL
  • Desain database: events, participants, categories, attendances, reports
  • Backend Laravel: auth, CRUD event, registrasi peserta, QR code check-in
  • Frontend Blade templates dengan Tailwind CSS buat UI responsif
  • Fitur QR code attendance — scan saat event buat tracking kehadiran real-time
  • Dashboard admin: kelola event, lihat statistik partisipasi, export laporan CSV/PDF
  • Sistem notifikasi email otomatis buat konfirmasi & reminder event
  • Deploy ke InfinityFree shared hosting buat demo kompetisi

R Result

  • Platform event management fungsional lengkap dengan 4 modul utama
  • Produk andalan tim di Creanomic Vokasi UB 2025
  • Live demo: greenevent.infinityfree.me
  • Source: GitHub
  • Validasi skill: Laravel full-stack + QR integration + event-driven workflow
