Web Ulang Tahun

Website interaktif untuk memberi ucapan ulang tahun dengan sentuhan personal.

Deskripsi

Web Ulang Tahun adalah sebuah script sederhana berbasis HTML, CSS, dan JavaScript yang dirancang untuk menampilkan ucapan ulang tahun secara menarik. Proyek ini ditujukan sebagai cara kreatif untuk menunjukkan perhatian kepada teman atau keluarga, sekaligus sebagai bukti kemampuan dasar seorang programmer dalam membuat website interaktif.

Tujuan

  • Memberikan pengalaman unik saat memberi ucapan ulang tahun.
  • Menyediakan template sederhana yang bisa dengan mudah dimodifikasi.
  • Menjadi contoh praktis penggunaan HTML, CSS, dan JavaScript bersama.

Fitur

  • Tampilan ucapan ulang tahun yang bisa disesuaikan.
  • Mudah diganti teks ucapan sesuai kebutuhan.
  • Animasi sederhana dengan JavaScript untuk membuat suasana lebih hidup.
  • Dapat dijalankan langsung di browser tanpa server tambahan.

Cara Menggunakan

  1. Clone repositori: 
    git clone https://github.com/sternnaufal/projekulangtahun.git
cd projekulangtahun
  2. Buka file index.html di browser.
  3. Edit teks ucapan ulang tahun di dalam file HTML sesuai keinginanmu.

Catatan

Script ini sederhana, tetapi fleksibel untuk dimodifikasi. Kamu bisa menambahkan animasi lain, mengganti warna tema, atau menambahkan musik agar ucapan ulang tahun terasa lebih spesial.
