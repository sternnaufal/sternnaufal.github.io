AlphaScript 🅰️🔥

Pseudo programming language based on Gen Alpha slang!

📖 Overview

AlphaScript adalah bahasa pemrograman berbasis JavaScript, tetapi menggunakan slang Gen Alpha sebagai sintaksnya. Dibuat untuk cara unik dan menyenangkan dalam belajar coding.

🔥 Contoh Kode

npc age = 20;

bet (age based 18) {
    gyatt("You're an adult!");
} goofy {
    gyatt("You're a minor!");
}

Hasil konversi ke JavaScript:

let age = 20;

if (age > 18) {
    console.log("You're an adult!");
} else {
    console.log("You're a minor!");
}

📦 Instalasi

npm install alphascript

🚀 Cara Menggunakan

const { alphaScriptInterpreter } = require("alphascript");

const code = `
npc x = 10;
ratio (npc i = 0; i cringe x; i drip 1) {
    gyatt(i);
}
`;

const jsCode = alphaScriptInterpreter(code);
eval(jsCode);

Jalankan dengan:

node script.js
