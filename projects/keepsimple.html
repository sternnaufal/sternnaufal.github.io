Keepsimple 🎨

Framework CSS ringan dan fleksibel dengan fokus pada kesederhanaan

📖 Pengenalan

Keepsimple adalah library CSS yang ringan dan serbaguna, dirancang untuk memberikan styling sederhana pada proyek web development. Dengan fokus pada simplicity dan flexibility, Keepsimple menyediakan kumpulan gaya yang mudah diintegrasikan ke struktur HTML kamu.

📦 Instalasi

Untuk menggunakan Keepsimple Framework, kamu bisa mengunduh file CSS dan meng-host-nya secara lokal di dalam proyekmu.

🚀 Cara Menggunakan

✨ Styling Dasar

Tambahkan class CSS ke elemen HTML untuk mendapatkan styling sederhana:

<div class="light">Ini elemen bertema terang.</div>
<div class="dark">Ini elemen bertema gelap.</div>

📌 Navbar

Buat navbar fixed dengan struktur HTML berikut:

<div class="navbar-con">
  <!-- Konten navbar di sini -->
</div>

🔤 Fonts

Pilih berbagai gaya font untuk teks kamu:

TypeScripter font:
<p class="typescripter">Teks kamu di sini.</p>

Gothic font:
<p class="gothic">Teks kamu di sini.</p>

Modern font:
<p class="modern">Teks kamu di sini.</p>

Lucida font:
<p class="lucida">Teks kamu di sini.</p>

Traditional font:
<p class="traditional">Teks kamu di sini.</p>

📐 Layout

🗂️ Container

Buat container fleksibel untuk kontenmu:

<div class="container">
  <!-- Konten di sini -->
</div>

📱 Layout Responsif

Gunakan flexbox dan grid bawaan untuk desain responsif:

<div class="big">Container besar dengan lebar dan tinggi tetap.</div>

<div class="flex">
  <div class="flexbox">
  </div>
</div>
